[GitHub 429][def5]

解决 GitHub raw / gist 资源频繁 429 限流：将请求头 Accept-Language 改写为 en-us，规避针对中文指纹的限流分支。使用前需在 Loon 中开启 MitM 并信任证书；若仍 429，说明出口 IP 已被限，请降低请求频率或改用 jsDelivr 镜像。

```ini
https://raw.githubusercontent.com/cacads/For-own-use/master/Loon/Plugin/gitHub429.plugin
```
